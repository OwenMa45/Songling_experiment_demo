# 接口、数据与仿真边界

## 动作和状态

长度均为 14：`holder_joint1..6, holder_width, squeezer_joint1..6, squeezer_width`。
关节使用弧度，夹爪使用两指总开度（米，0–0.07）。传给环境和策略客户端的动作都是绝对位置目标；训练适配层将两组 6 关节转换为相对于观测状态的增量，夹爪保持绝对开度，推理输出再恢复绝对关节目标。没有 ALOHA 的关节翻转或夹爪角度变换。

物理步长 0.002 秒，控制频率 20 Hz。控制目标经过限位、限速并在物理子步插值。模型使用明确的重力补偿；真实控制器是否提供相同补偿需要验证。PiPER 上游执行器限位与 joint range 的差异在生成器中统一为 joint range。

`reset(target, seed, randomized)`、`observe()`、`step(action)`、`report()` 构成仿真接口。`step` 之后检查 `done`；停止后继续仿真 1.5 秒以统计残余滴液。观测包含 HWC RGB uint8 的 `image`、`wrist_image`、14 维 `state` 和自然语言 `prompt`。

策略客户端每次最多执行 4 个动作后重新观测；每个物理子步仍检查外部计数与碰撞。连接/响应默认 10 秒超时，不无限重试。仿真在等待策略时暂停；此同步客户端不是真机实时控制器，真机必须有独立运行的看门狗和计数监督。

## 滴管模型

玻璃部分固定在持管臂工具坐标系中，不仿真抓持滑移。胶头是视觉上随压缩变化的简化形体；**没有真实橡胶软体求解或接触反力**。只有夹捏 TCP 距离和姿态满足阈值时，夹爪闭合才驱动压缩模型。此近似需要真机校准，不能用于推断玻璃应力或夹持力。

正向压缩排出有限体积，压力按时间常数衰减，释放不自动补液；累计达到单滴体积后产生离散液滴。液滴按重力下落，发射位置位于试管口投影内且高于管口才算入管，否则计为外溢。液滴可渲染，但不模拟壁面接触、飞溅、黏附、弯月面、试剂反应或气泡。

`Counter.read()` 是独立计数接口。当前 `SimulationCounter` 读取几何事件真值；真实视觉计数器尚未实现。液量、压力、真实滴数不进入 π0.5 输入。脚本专家可以读取仿真计数以制作示范，部署策略不能读取该仿真真值。

随机化包括试管平面位置、相机位置、光照、排液系数和 0–2 个控制步延迟。种子固定可复现。真实试管坐标、TCP、相机和胶头尺寸未测量前，默认参数只用于构建初始场景。

## 原始示范与真实数据导入

每回合目录包含 `episode.json` 和逐帧 `000000.npz` 等文件。每帧字段：

| 字段 | 形式 | 含义 |
| --- | --- | --- |
| state | float32 [14] | 动作执行前的实测关节/开度 |
| action | float [14] | 该控制步限速后下发的绝对目标 |
| image / wrist_image | uint8 [H,W,3] | 动作执行前 RGB，两个相机各自同步 |
| timestamp | float64 标量 | 单调秒时间，默认间隔 0.05 秒 |

元数据包括 `schema=piper-titration-v1`、`order`（上述固定顺序）、`fps`、`frames`、`prompt` 和 `report.success`。仿真额外记录完整配置、目标、随机种子和随机化开关，以支持回放。

真实数据可用 `Recorder` 写入相同格式：自行同步图像、状态、已下发目标到 20Hz，再设置成功标签；不能把下一帧状态冒充该帧控制指令。转换器接受符合相同规范的真实回合，检查形状、帧数、有限值和时间间隔。真实回合无需可回放的仿真配置；`replay` 仅适用于本项目记录的仿真回合。

转换器不推断成功、不插值不规则数据、不上传外部服务。训练集统计不会包含测试回合。测试数据集用于后续离线研究；当前主要验收为闭环仿真评估。

## 真机前必须测量的参数

- 两台机械臂的实际型号、安装变换、关节零位、关节/夹爪限位。
- 滴管在夹爪内的固定姿态、胶头中心、尖端偏移、试管口位置与半径。
- 相机内外参、图像方向、曝光、腕部视角遮挡和液滴可见性。
- 胶头夹捏开度/速度与出液量、单滴体积、释放延迟、剩余液量的关系。
- 真实控制频率、延迟、停止动作与残余出液，以及计数漏检/误检。

本项目不会连接 CAN、发送真机动作或声称仿真策略已具备直接上机条件。
